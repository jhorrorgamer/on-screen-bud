# On-Screen Buddy

A tiny desktop buddy app built with Python + Tkinter.

## Features

- Spawns a cute, randomly generated buddy each run.
- Buddy has random body color, mood, and accessory.
- Always-on-top window so your buddy can hang out on your desktop.
- Gentle idle bobbing animation.
- Click + drag to move the buddy around.
- Double-click the buddy to generate a brand-new friend.
- Press `Esc` to close the app.

## Run

```bash
python3 buddy_app.py
```

Tkinter is included with most Python installations by default.
